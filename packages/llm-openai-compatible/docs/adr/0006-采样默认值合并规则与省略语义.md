# 0006-采样默认值合并规则与省略语义

采样默认值合并规则：`temperature` = `options.temperature ?? profile.temperature`
（都不给 → 不发送，提供方默认）；`max_tokens` = `options.maxTokens ??
model.maxTokens ?? profile.defaultMaxTokens`（都不给 → 不发送）；`top_p` /
`presence_penalty` / `frequency_penalty` / `seed` 取 profile 值（undefined →
不发送）；`top_k` 经 `providerOptions` 透传进请求体（非标准，仅网关支持时
发送）；`reasoning_effort` 非 `off` 档位发送声明值、`off` → 不发送。

## 考虑过的选项

- **总是发送全部采样参数**：提供方默认值被覆盖，且非标准字段（`top_k`）
  对不支持它的端点会报错。
- **请求级参数缺失时抛错**：用户必须显式配置每个参数，迁移成本高。

## 后果

- 省略语义 = 不发送 = 提供方默认——配置最小化，迁移 `llm-pi-ai` 配置时
  未写的字段自然回落。
- `max_tokens` 的三级回落（请求 → 模型 → profile 默认）使模型级
  `maxTokens` 成为 per-request 默认输出上限。
