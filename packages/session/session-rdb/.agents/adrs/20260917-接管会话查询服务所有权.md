# 接管会话查询服务所有权

状态：已采纳

## 背景

`ctx.sessionQuery` 是会话历史的统一查询面：精确读（list / read / filter /
title / surface / event window）、血缘与事件关系追踪（trace）、语义文档抽取，
以及全文检索。官方实现（`@deepseek-ai/dsh-session-query` 契约 +
`@deepseek-ai/dsh-session-query-sqlite` 后端）拆成两层：契约包的
`SessionQueryEngine` 里 15 个公开方法有 13 个是与 backend 无关的具体实现
（数据面经 `ctx.sessions` 与 `ctx.sessionPersistence`），只有
`searchSessions` / `searchEvents` 是 abstract。

官方 sqlite 后端自带一份**派生 SQLite 索引库**（FTS5 + per-record 文档表 +
live 影子表），但在当前装配中被配成 `path: ':memory:'`、`openAt: never`——
搜索恒为 disabled，派生库从不打开。也就是说：**它此刻唯一实际承担的职责，
是提供 `ctx.sessionQuery` 这个服务键**；其具体方法全部跑在我们的持久化数据上。

## 决策

1. **服务所有权迁到 rdb**：禁用官方 `session-query-sqlite` 装配行（同名
   provide 会 fail loud，必须禁用），由本包按 cordis class-plugin 装载
   `SessionQueryRdb extends SessionQueryEngine`（`src/session-query.ts`）提供
   同名 `ctx.sessionQuery`。精确读 / 过滤 / 血缘 / title / surface 全部复用
   上游基类，数据面继续走 `ctx.sessionPersistence`（rdb）与 `ctx.sessions`。
2. **全文检索维持 disabled**：两个 abstract 方法与官方 `openAt: never` 逐字
   同形地抛 `SESSION_QUERY_SEARCH_DISABLED`（异步拒绝，不归一化请求、不做任何
   索引工作），不引入 FTS5 派生库、`node:sqlite` 或第三个介质文件。语义化搜索
   是独立决策（需要 cursor / ranking / stale 语义），留待显式立项。
3. **不复制上游实现**：不 fork 契约包与 sqlite 后端的代码，只继承基类；升级时
   15 个方法签名与错误码闭集由编译期暴露（fail loud）。

## 考虑过的选项

- **保持官方 sqlite 后端装载**：服务可用，但为一份从不打开的 FTS 索引库付
  装载成本与升级面积；且它的 `_reconcile` 观测状态机与派生库 schema 属于
  我们要长期跟随的另一套存储。
- **只禁用不接管**：`ctx.sessionQuery` 缺失会让 `api/session-controller`
  （`static inject`）、subagent listing、`session-log-export`、`ui-deliverables`
  等一批消费者直接装载失败。
- **复制上游基类实现到 rdb**：927 行等价逻辑 + 契约测试长期跟随，收益为零。
- **档 B：用 rdb SQL 实现真搜索**：需要对齐上游的 snippet 码点截断、确定性
  排序、cursor generation / stale 语义与 live 尾巴（rdb 批量落库 200ms 延迟，
  必须用内存快照做 live 影子）。作为独立变更评估，留待显式立项。

## 后果

- `SessionQueryRdb` 必须按 class-plugin 装载（`ctx.plugin`）：直接 `new` 不会
  执行 `[Service.init]`，服务生命周期与依赖等待都会失效。
- 搜索调用方（Web 侧边栏内容搜索、`tool-session-query`）继续得到
  `SESSION_QUERY_SEARCH_DISABLED`，与官方当前装配行为一致。
- `packages/session/better-session/cordis.patch.yml` 增加
  `session-query-sqlite: disabled`；[README](../../README.md) 与 [设计 20260917-系统设计](../../../../../.agents/designs/20260917-系统设计.md) 同步。
