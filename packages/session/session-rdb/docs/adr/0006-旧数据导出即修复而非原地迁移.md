# 0006-旧数据导出即修复而非原地迁移

旧格式数据（旧表结构下的数据格式、surface 语义损坏）的修复**并入导出路径**
（`readRaw`），产出**完备可用**的 JSONL artifact；修复只作用于导出视图、
**不落库**——写路径零转换不变量不变。现状与修复明细见
[legacy-clean.md](../legacy-clean.md) 与 [read-path.md](../read-path.md)。

## 考虑过的选项

- **原地修复数据行**：破坏「写路径零转换」不变量，且修复逻辑与写路径
  耦合；历史加载失败的会话无法修复。
- **单独修复脚本**：需要维护与导出路径重复的解析逻辑，且用户必须知道
  何时运行。

## 后果

- 表结构级迁移与门禁见 [schema.md](../schema.md)；导出即修复只处理同版本内的
  数据格式差异。
- 历史加载失败的会话仍可正常导出，导出的 zip 导入后即为可用的新会话。
