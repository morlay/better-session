状态：**已实现**（四层服务 + 装配 bundle 已落地，示例工作区的 web 与 desktop 两种模式可跑）
范围：本仓库全部包的职责、分层、装配与操作语义——包清单与门面见[根 `README.md`](../../README.md)，各包内部实现细节在包层
`.agents/`，上游同步 / 适配流程在 `.agents/skills/`。
约束：**不改上游、不改 vendor**（`@deepseek-ai/*` 与 `vendor/**` 只读，扩展只走 cordis 插件层与本地 patch）。

分支式会话编辑：在不修改上游 `@deepseek-ai/*` 代码的前提下，为 DeepSeek Harness
会话提供 **就地编辑 / 重试 / 撤回 / 分支**（rewind / retry / recall / fork）闭环——GUI
里撤回用户消息到输入框或就地重写、重试任意回合，重写**同一会话**（session id
不变），只有分支才派生新 id。领域术语与全部包的上下文归属见
[`CONTEXT-MAP.md`](../CONTEXT-MAP.md)。

## 分层模型

三层 cordis plugin，依赖单向向下：

```
契约层  @morlay/session-branch                provider 抽象 + 版本树投影
   ▲        ▲
   │        │
编排层  @morlay/ui-conversation-message-actions   SessionEditor 编排 + client UI（chat 节点替换 + composer 统计行覆盖）
   │        │
实现层  @morlay/session-rdb                  RDB 持久化 + branch provider 双服务
```

| 层     | 包                                        | 职责                                                                                                                                                                                     |
| ------ | ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 契约层 | `@morlay/session-branch`                  | `SessionBranchProvider` 抽象（rewind / forkFrom / readBranchPrefix）+ `SessionBranch` 服务 + `buildTimeline` 版本树投影                                                                  |
| 编排层 | `@morlay/ui-conversation-message-actions` | `SessionEditor` 编排（edit / retry / recall / fork 完整功能）+ client bundle（`conversation.chat.node` 的 `user` / `steering` 渲染替换、`conversation.composer.dock` 的 `stats` 行覆盖） |
| 实现层 | `@morlay/session-rdb`                     | RDB 持久化（实现上游 `SessionHandle` 模型）+ 分支 provider（实现 `SessionBranchProvider`）+ storages 接管（投影缓存服务与 workspace 域 KV 后端）                                         |
| 聚合   | `@morlay/better-session`                  | profile bundle：`cordis.patch.yml` 一次性装配以上全部到 web profile                                                                                                                      |

client 半（浏览器）除编排层自己的 bundle 外，还依赖对话 UI 接管包与样式基础（`session/ui-conversation`、
`client/ui-primitives`），并在官方行之上替换 / 覆盖上述两个槽位——接管形态与回退条件见
[债务 临时接管上游对话UI的client半](../../packages/session/ui-conversation/.agents/debts/20260917-临时接管上游对话UI的client半.md)，
操作语义与浏览器半细节见
[设计 编排层操作语义](../../packages/session/ui-conversation-message-actions/.agents/designs/20260917-编排层操作语义.md)。

## 装配（`@morlay/better-session` bundle patch）

`cordis.patch.yml` 一次装配四层服务：持久化（RDB，替换官方 jsonl）、分支数据、edit / retry / recall / fork 编排、
`conversation.chat.node` 渲染替换，并把官方 `ui-conversation` 行换成 fork 行 + 插入编排层与样式基础。装配链与服务调用
示例见 [packages/session/better-session/README.md](../../packages/session/better-session/README.md)，rdb 替换的起因与权衡见
[ADR-20260917-rdb替换官方jsonl持久化](../../packages/session/better-session/.agents/adrs/20260917-rdb替换官方jsonl持久化.md)。

默认配置为 SQLite（`$DSH_HOME/sessions/sessions.sqlite`）；`session-rdb` namespace 的 `connectionString` 可切 PostgreSQL；
官方 `session-persistence-jsonl` 被禁用（`disabled: true`）。

同批接管的官方行由 session-rdb 提供同名服务：`storage-json` / `session-projection-cache`（workspace 域 KV 与投影
checkpoint 落 RDB 语义表）与 `session-query-sqlite`（精确读 / 过滤 / 血缘复用上游 `SessionQueryEngine` 基类，全文检索维持
disabled）——起因与权衡各在
[ADR-接管storages到rdb语义表](../../packages/session/session-rdb/.agents/adrs/20260917-接管storages到rdb语义表.md) 与
[ADR-接管会话查询服务所有权](../../packages/session/session-rdb/.agents/adrs/20260917-接管会话查询服务所有权.md)。

装配面判据（patch 的每个 insert 行可解析到真实包且属本 bundle 依赖、依赖不漏装配、fork 的 client 包声明
`client-modules` 需要的入口与平台）与守护测试见
[packages/session/better-session/.agents/standards/how-to-verify.md](../../packages/session/better-session/.agents/standards/how-to-verify.md)。

## 操作语义

`edit` / `retry` / `reroll` 就地重写同一会话（`rewind` 截断 + `append` 重放，session id 不变）；`recall` 只 `rewind` 截断
并把消息文本交回 composer（不重放）；只有 `fork` 派生新 id。落在被截断区间里的**完整压缩事务会在重写时补回**（重排为
standalone 形态，保证摘要仍生效、压缩仍可再触发，见
[编排层 ADR-20260917-压缩事务在重写时补回](../../packages/session/ui-conversation-message-actions/.agents/adrs/20260917-压缩事务在重写时补回.md)）。
各操作的完整语义见
[设计 20260917-编排层操作语义](../../packages/session/ui-conversation-message-actions/.agents/designs/20260917-编排层操作语义.md)。

  （[ADR-20260917-分支面作为与上游SessionHandle平行的provider抽象](../../packages/session/session-branch/.agents/adrs/20260917-分支面作为与上游SessionHandle平行的provider抽象.md)）。

  （[ADR-20260917-rdb替换官方jsonl持久化](../../packages/session/better-session/.agents/adrs/20260917-rdb替换官方jsonl持久化.md)）。

  （[债务 临时接管上游对话UI的client半](../../packages/session/ui-conversation/.agents/debts/20260917-临时接管上游对话UI的client半.md)）。

  （[ADR-20260917-自研离线桌面打包器而非直接用上游桌面应用](../adrs/20260917-自研离线桌面打包器而非直接用上游桌面应用.md)）。
