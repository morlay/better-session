# 规范（standards）

这里放**必须遵守的项目约束**——不是建议、不是背景知识。这一层只放**通用**规范，分两份：

| 文件                                   | 回答                                                       |
| -------------------------------------- | ---------------------------------------------------------- |
| [how-to-write.md](./how-to-write.md)   | 写代码时守什么：接缝在哪、分层与依赖方向、包出口、代码约定 |
| [how-to-verify.md](./how-to-verify.md) | 怎么算验证过：证据矩阵、测试落点、交付与发布、失败怎么处理 |

**项目 / 包特有**的规范（某个包的接缝、判据、环境门控）写在那**包**的 `.agents/standards/`——就近查，
这里不索引、不复述。

规矩：

- 规范只在**一个** home 定义：通用规范在这里，项目 / 包特有的规范在该包 `.agents/standards/`；
  `README.md`、设计文档、ADR、技能里都不复述，只链接（home 表见 [`AGENTS.md`](../../AGENTS.md)）。
- 技术栈与版本见 [`mise.toml`](../../mise.toml)；命令入口见 [`justfile`](../../justfile)（`just --list`）——
  这里不复制清单。
- 规范冲突时按各层 `.agents/adrs/` 的决策走（当前决策在根 [`adrs/`](../adrs) 与各包 `.agents/adrs/`）；
  要改规范，先改这里再改代码。
- 流程与做法（何时做、怎么做）不进这里，它们在 [`.agents/skills/`](../skills)。
